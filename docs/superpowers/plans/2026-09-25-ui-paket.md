Der Zustand eines Vertrags ist die Nachricht in `state.proto`; die Ersetzung läuft über `replace()` und `registerRootWrapper()`; `examples/mui-adapter/` entfällt zugunsten von #29661 im Framework, im Paket bleibt `tools/roles-to-mui.mjs`. Begründung: `docs/skalen.md` „Ein Vertrag, zwei Hälften“.

**Goal:** Ein Kundenmodul ersetzt benannte TopLogic-Ressourcen und ersetzt React-Komponenten unter TopLogic-Namen mit `replace()`; jede Komponente der MBUI-Schnittmenge hat einen Vertrag in Muss und Kann, dessen Zustand die Nachricht in `state.proto` ist; ein Konformitätstest-Harness in der Bridge prüft das Muss, unsere Controls bestehen ihn zuerst; das Paket rechnet die Rollen als Hex je Modus für eine fremde Bibliothek (`roles-to-mui.mjs`, Abnehmer #29661); ein Theme darf ein UI-Paket benennen.

**Architecture:** Framework (`~/git/tl8-wt-29584`, Modul `com.top_logic.layout.react`): `@Key` an der Ressourcenliste macht `config:operation` auf benannte Einträge wirksam; Vitest mit jsdom bei der Bridge (Muster !1705) trägt den Harness, der eine registrierte Komponente im Bridge-Kontext mit dem Zustand eines Konformitätsfalls mountet, die Schlüssel des Falls gegen das Schema aus `react-src/state/control-state.ts` prüft und die Kommandos am gestubbten Kommandokanal liest; `package` am Ressourceneintrag und `ui-package` am Theme filtern die Ressourcenliste je aktivem Theme. Zustand: `state.proto` aus !1698 (msgbuf, Java und TypeScript aus einer Quelle; `TestControlStateSchema` prüft den Server). Paket (`design-system/`): Verträge als `*.contract.md` mit `## Muss` (`### Zustand` als Verweis auf die Proto-Nachricht, `### Aktionen`, `### Stapel`), `## Kann`, `## Konformität` mit einem JSON-Block; `publish-to-worktree.mjs` kopiert die Verträge in die Bridge und holt `state.proto` als Prüfkopie zurück; `tools/roles-to-mui.mjs` schreibt die Rollen aus `dist/` als Hex je Modus. Theme-Richtung: `derive` → Rollen → `roles-to-mui` → `createTheme`, nie umgekehrt.

**Tech Stack:** Java 21 + TypedConfiguration + JUnit 3 (Framework); msgbuf 1.2.3 mit TypeScript-Ziel (`state.proto` → `control-state.ts`, aus !1698); TypeScript, React 19, Vite 6, Vitest 3, `@testing-library/react` 16, `@testing-library/user-event` 14, jsdom 26 (Bridge-Harness, wie !1705); Node 22, `node:test`, keine Abhängigkeit (Paket, auch `roles-to-mui.mjs`).

**Spec:** `docs/superpowers/specs/2026-09-25-ui-paket-design.md`

```java
		+ "<stylesheet name='components' config:operation='remove'/>"
		+ "<module-script name='mbui' resource='/script/mbui.js' requires='controls'/>"

	private static final String DANGLING = "<config class='" + ClientResources.class.getName() + "'" + NS + ">"

		+ "<stylesheet name='tokens' config:operation='remove'/>"
		+ "</resources>"
		+ "</config>";

	/** The second fragment removes an entry by name and keeps the rest, in dependency order. */
	public void testRemoveByName() throws ConfigurationException, IOException {
		String styles = styles(service(BASE, CUSTOMER));

		assertTrue(styles, styles.contains("/style/tokens.css"));
		assertFalse(styles, styles.contains("/style/components.css"));
	}

	/** The second fragment replaces the resource of a named entry. */
	public void testUpdateByName() throws ConfigurationException, IOException {
		String styles = styles(service(BASE, REPLACE));

		assertTrue(styles, styles.contains("/style/mbui.css"));
		assertFalse(styles, styles.contains("/style/components.css"));
		assertTrue(styles, styles.indexOf("/style/tokens.css") < styles.indexOf("/style/mbui.css"));
	}

	/** A module script added by the customer is emitted after the one it requires. */
	public void testCustomerScriptAfterOurs() throws ConfigurationException, IOException {
		String scripts = scripts(service(BASE, CUSTOMER));

		assertTrue(scripts, scripts.indexOf("/script/controls.js") < scripts.indexOf("/script/mbui.js"));
	}

	public void testRequiresOnRemovedEntryIsAnError() throws ConfigurationException {

		service.writeScriptRefs(new TagWriter(buffer), "");
```

### Task 4: Der Harness

Der Harness liest einen Vertrag und das Schema. Aus dem Vertrag nimmt er zwei Dinge: den Namen der Proto-Nachricht unter `### Zustand` und die Fälle aus dem JSON-Block unter `## Konformität`. Das Schema liest er aus `react-src/state/control-state.ts` — die exportierten Interfaces, die msgbuf aus `state.proto` erzeugt, mit ihren `extends`-Ketten.
```ts
// Der Konformitätstest-Harness (Spec 2026-09-25-ui-paket-design.md §5). Er prüft den Muss-Teil eines
// Vertrags gegen die Komponente, die unter dem TopLogic-Namen registriert ist. Der Zustand ist die
// Nachricht in state.proto; ihr Schema kommt aus dem erzeugten control-state.ts. Er ist das Werkzeug
// des Kunden vor seinem Deploy; unsere eigenen Controls bestehen ihn zuerst.
import { describe, it, expect, beforeEach } from 'vitest';
import { render, cleanup, act } from '@testing-library/react';
import userEvent from '@testing-library/user-event';
import { React, getComponent, TLControlContext, KeyboardScopeProvider } from 'tl-react-bridge';
import { wrapRoot } from '../bridge/root-wrapper';
import { commandLog, settle } from './test-setup';

interface Case {
  name: string;
  state: Record<string, unknown>;
  trigger: string;
  on?: string;
  expect: { command: string; args?: Record<string, unknown> } | null;
  trap?: boolean;
  renders?: false;
  dom?: { selector?: string; attributes?: Record<string, string | null>; text?: string; classes?: string[] };
}

export interface Contract {
  module: string;
  message: string;
  cases: Case[];
}

export type Schema = Map<string, Set<string>>;

const CONTROL_ID = 'c1';

function section(markdown: string, heading: RegExp): string | undefined {
  const parts = markdown.split(heading);
  if (parts.length < 2) return undefined;
  return parts[1].split(/^##+ /m)[0];
}

/** Die Nachricht unter "### Zustand" und der JSON-Block unter "## Konformität". Alles andere ist für Menschen. */
export function readContract(markdown: string): Contract {
  const zustand = section(markdown, /^### Zustand\s*$/m);
  const names = new Set([...(zustand ?? '').matchAll(/`(\w+State)`/g)].map((m) => m[1]));
  if (names.size !== 1) throw new Error(`"### Zustand" nennt ${names.size} Nachrichten statt genau einer`);
  const konf = markdown.split(/^## Konformität\s*$/m)[1];
  if (!konf) throw new Error('Vertrag ohne Abschnitt "## Konformität"');
  const block = /```json\s*([\s\S]*?)```/.exec(konf);
  if (!block) throw new Error('Kein JSON-Block unter "## Konformität"');
  const parsed = JSON.parse(block[1]) as { module: unknown; cases: unknown };
  if (typeof parsed.module !== 'string' || !Array.isArray(parsed.cases)) {
    throw new Error('Konformität braucht "module" und "cases"');
  }
  return { module: parsed.module, message: [...names][0], cases: parsed.cases as Case[] };
}

/** Die exportierten Interfaces von control-state.ts: je Nachricht alle Schlüssel samt geerbten. */
export function readSchema(source: string): Schema {
  const own = new Map<string, { parent?: string; keys: string[] }>();
  const decl = /^export interface (\w+)(?: extends (\w+))? \{(?:\}|([\s\S]*?)^\})/gm;
  for (const m of source.matchAll(decl)) {
    own.set(m[1], { parent: m[2], keys: [...(m[3] ?? '').matchAll(/^\t(\w+)\??:/gm)].map((k) => k[1]) });
  }
  const all = (name: string): string[] => {
    const entry = own.get(name);
    return entry ? [...(entry.parent ? all(entry.parent) : []), ...entry.keys] : [];
  };
  return new Map([...own.keys()].map((name) => [name, new Set(all(name))]));
}

/** "<Fall>: <Schlüssel>" für jeden Schlüssel eines Falls, den die Nachricht nicht deklariert. */
export function undeclaredKeys(contract: Contract, schema: Schema): string[] {
  const keys = schema.get(contract.message);
  if (!keys) return [];
  return contract.cases.flatMap((c) => Object.keys(c.state ?? {}).filter((k) => !keys.has(k)).map((k) => `${c.name}: ${k}`));
}

/** Ein Zustandsspeicher, wie ihn die Bridge je Control führt — hier ohne SSE. */
function store(state: Record<string, unknown>) {
  let current = { ...state };
  const subscribers = new Set<() => void>();
  return {
    getSnapshot: () => current,
    subscribeStore: (cb: () => void) => { subscribers.add(cb); return () => subscribers.delete(cb); },
    replaceState: (next: Record<string, unknown>) => { current = { ...next }; subscribers.forEach((cb) => cb()); },
    applyPatch: (patch: Record<string, unknown>) => { current = { ...current, ...patch }; subscribers.forEach((cb) => cb()); },
  };
}

/** Mountet wie die Bridge: Wurzel-Wrapper des Kunden außen, dann Control-Kontext und Tastatur-Scope. */
function mountCase(module: string, state: Record<string, unknown>) {
  const Component = getComponent(module);
  if (!Component) throw new Error(`Modul ${module} ist nicht registriert — kein Vertrag ohne Komponente`);
  const value = { controlId: CONTROL_ID, windowName: 'test', store: store(state) };
  return render(wrapRoot(
    React.createElement(KeyboardScopeProvider, null,
      React.createElement(TLControlContext.Provider, { value: value as never },
        React.createElement(Component, { controlId: CONTROL_ID, state })))));
}
```

Die Hilfsfunktionen `target`, `fire` und `gestureToUserEvent` bleiben, wie sie sind (Auslöser `click`, `enter`, `space`, `escape`, `backdrop`, `gesture:`, `change:`, `select:`, `range:`, `none`):

```ts
/** Das Element, das den Auslöser bekommt: das Control selbst oder das erste Bedienelement darin. */
function target(container: HTMLElement, on?: string): HTMLElement {
  if (on) {
    const chosen = container.querySelector<HTMLElement>(on);
    if (!chosen) throw new Error(`Auslöser-Ziel ${on} nicht gefunden`);
    return chosen;
  }
  const byId = container.querySelector<HTMLElement>('#' + CONTROL_ID);
  const el = byId ?? container.firstElementChild as HTMLElement | null;
  if (!el) throw new Error('nichts gerendert');
  const inner = el.matches('button,input,select,textarea,[tabindex]') ? el
    : el.querySelector<HTMLElement>('button,input,select,textarea,[tabindex]');
  return inner ?? el;
}

async function fire(trigger: string, container: HTMLElement, on?: string) {
  const user = userEvent.setup();
  const el = target(container, on);
  if (trigger === 'click') { await user.click(el); return; }
  if (trigger === 'enter') { el.focus(); await user.keyboard('{Enter}'); return; }
  if (trigger === 'space') { el.focus(); await user.keyboard(' '); return; }
  if (trigger === 'escape') { el.focus(); await user.keyboard('{Escape}'); return; }
  if (trigger === 'backdrop') { await user.click(container.querySelector<HTMLElement>('#' + CONTROL_ID)!); return; }
  if (trigger.startsWith('gesture:')) {
    // Die Geste geht an das Dokument; der Dispatcher der Bridge leitet sie in den Scope.
    const { initKeyboardDispatcher } = await import('../bridge/keyboard-dispatcher');
    initKeyboardDispatcher();
    await user.keyboard(gestureToUserEvent(trigger.slice('gesture:'.length)));
    return;
  }
  if (trigger.startsWith('change:')) {
    const input = el as HTMLInputElement;
    await user.clear(input);
    await user.type(input, trigger.slice('change:'.length));
    await user.tab();
    return;
  }
  if (trigger.startsWith('select:')) {
    await user.selectOptions(el, trigger.slice('select:'.length));
    return;
  }
  if (trigger.startsWith('range:')) {
    // Ein Schieberegler nimmt keine Tastatureingabe an: Wert setzen, change und pointerup auslösen.
    const { fireEvent } = await import('@testing-library/react');
    fireEvent.change(el, { target: { value: trigger.slice('range:'.length) } });
    fireEvent.pointerUp(el);
    return;
  }
  if (trigger === 'none') return;
  throw new Error(`unbekannter Auslöser ${trigger}`);
}

/** "Ctrl+S" → "{Control>}s{/Control}", "Escape" → "{Escape}", "Enter" → "{Enter}" (Schreibweise des Servers). */
function gestureToUserEvent(gesture: string): string {
  const parts = gesture.toUpperCase().split('+');
  const key = parts.pop()!;
  const named: Record<string, string> = { ESCAPE: '{Escape}', ENTER: '{Enter}', SPACE: ' ', TAB: '{Tab}' };
  const keyText = named[key] ?? key.toLowerCase();
  const mods = parts.map((m) => ({ CTRL: 'Control', SHIFT: 'Shift', ALT: 'Alt', META: 'Meta' })[m] ?? m);
  return mods.map((m) => `{${m}>}`).join('') + keyText + mods.reverse().map((m) => `{/${m}}`).join('');
}
```

```ts
export function runContract(contract: Contract, schema: Schema): void {
  if (!getComponent(contract.module)) {
    throw new Error(`kein Vertrag für Modul ${contract.module}: nicht registriert`);
  }
  const undeclared = undeclaredKeys(contract, schema);
  if (undeclared.length > 0) {
    throw new Error(`${contract.module}: Schlüssel, die ${contract.message} nicht deklariert: ${undeclared.join(', ')}`);
  }
  if (!schema.has(contract.message)) {
    // Eine geplante Nachricht (contracts.test.mjs im Paket führt die Liste): die Fälle laufen, die Schlüssel sind ungeprüft.
    console.warn(`[conformance] ${contract.message} fehlt in control-state.ts (geplant): Schlüssel von ${contract.module} ungeprüft`);
  }
  describe(`Vertrag ${contract.module} (${contract.message})`, () => {
    beforeEach(() => cleanup());
    for (const c of contract.cases) {
      it(c.name, async () => {
        const { container } = mountCase(contract.module, c.state);
        if (c.renders === false) {
          expect(container.querySelector('#' + CONTROL_ID)).toBeNull();
          return;
        }
        if (c.trap !== undefined) {
          const { activeTrapCount } = await import('../bridge/focus-trap');
          expect(activeTrapCount() > 0).toBe(c.trap);
        }
        if (c.dom) {
          const el = c.dom.selector ? container.querySelector<HTMLElement>(c.dom.selector) : container.querySelector<HTMLElement>('#' + CONTROL_ID);
          expect(el, `DOM ${c.dom.selector ?? '#' + CONTROL_ID}`).not.toBeNull();
          for (const [name, value] of Object.entries(c.dom.attributes ?? {})) {
            if (value === null) expect(el!.hasAttribute(name), `${name} darf nicht gesetzt sein`).toBe(false);
            else expect(el!.getAttribute(name), name).toBe(value);
          }
          if (c.dom.text !== undefined) expect(el!.textContent?.trim()).toBe(c.dom.text);
          if (process.env.TL_CONFORMANCE_KANN && c.dom.classes) {
            for (const cls of c.dom.classes) expect(el!.classList.contains(cls), `Klasse ${cls}`).toBe(true);
          }
        }
        const sentCommands = () => commandLog.filter((e) => e.controlId === CONTROL_ID);
        await act(async () => { await fire(c.trigger, container, c.on); });
        await settle();
        // Ein entprelltes Feld sendet erst nach VALUE_DEBOUNCE_MS; der Harness wartet, statt zu raten.
        if (c.expect && sentCommands().length === 0) {
          const { VALUE_DEBOUNCE_MS } = await import('tl-react-bridge');
          await act(async () => { await new Promise((r) => setTimeout(r, VALUE_DEBOUNCE_MS + 50)); });
          await settle();
        }
        const sent = sentCommands();
        if (c.expect === null) {
          expect(sent).toEqual([]);
        } else {
          expect(sent.map((e) => e.command)).toContain(c.expect.command);
          if (c.expect.args) {
            const match = sent.find((e) => e.command === c.expect!.command)!;
            expect(match.args).toMatchObject(c.expect.args);
          }
        }
      });
    }
  });
}
```

````markdown
# Vertrag: Snackbar

Eine Kundenkomponente, die mit `replace()` unter dem TopLogic-Namen `TLSnackbar` steht (Stufe C). Eine flüchtige Meldung am
unteren Rand; der Server sagt, was und wie lange.

## Muss

### Zustand

`SnackbarState` in `state.proto`, TypeScript `SnackbarState` aus `tl-react-bridge`. Die Fälle unten
setzen `visible`, `message`, `duration`, `generation`.

### Aktionen

| Auslöser | Aktion |
|---|---|
| Ablauf der `duration`, Klick auf Schließen | `sendCommand('dismiss', { generation })`. |
| Zeigen mit der Maus | hält die Meldung; nach dem Verlassen läuft sie kurz nach und geht dann. |

### Stapel

Jede Meldung trägt ihre `generation`; `dismiss` nennt sie, damit der Server eine schon ersetzte
Meldung nicht schließt. Eine neue `generation` bei `visible: true` startet die Dauer neu.

## Kann

### Tokens

Noch kein Paket-CSS; folgt mit Welle 4. Bis dahin `--tl-status-<variant>-surface` und `--tl-text-on-status-<variant>` für die vier Bedeutungen.

### Attribute

| Attribut | Wann |
|---|---|
| `role="status"` | `info`, `success`: höflich angesagt. |
| `role="alert"` | `warning`, `error`: sofort angesagt. |
| `id="<controlId>"` | am Wurzelelement. |

### Aufzeichnung

Text unter `id="<controlId>"`.

## Konformität

```json
{ "module": "TLSnackbar", "cases": [

    "dom": { "text": "Gespeichert" } },

```
````

```js
// Rechnet die Rollen des Pakets als Werte je Modus für eine fremde Komponentenbibliothek. MUI rechnet
// contrastText und Hover-Töne selbst aus Hexwerten und kann mit var(--tl-…) nichts anfangen; darum
// zur Bauzeit. Richtung: derive → Rollen → hier → createTheme, nie umgekehrt (skalen.md „Ein Vertrag,
// zwei Hälften“). Abnehmer: das MUI-Adaptermodul im Framework (#29661). Erzeugt, nie von Hand geändert.
//
//   node tools/roles-to-mui.mjs                                  → dist/roles.generated.json
//   node tools/roles-to-mui.mjs <theme>.theme.css [<ausgabe>]    → <theme>.roles.json (Kundentheme)
import { readFileSync, writeFileSync } from 'node:fs';
import { fileURLToPath } from 'node:url';

const RULE = /([^{}]+)\{([^{}]*)\}/g;
const DECL = /--tl-([a-z0-9-]+)\s*:\s*([^;]+);/g;

/** Die --tl-Deklarationen aller Regeln, deren Selektorliste `selector` enthält, in Reihenfolge. */
function declarations(css, selector) {
  const out = {};
  for (const [, selectors, body] of css.replace(/\/\*[\s\S]*?\*\//g, '').matchAll(RULE)) {
    if (!selectors.split(',').map((s) => s.trim()).includes(selector)) continue;
    for (const [, name, value] of body.matchAll(DECL)) out[name] = value.trim();
  }
  return out;
}

/**
 * Rollen je Modus. Dunkel erbt aus hell, was es nicht setzt; ein Theme überschreibt beide Modi mit
 * seinem Block und dunkel zusätzlich mit seinem dunklen Block — wie die Kaskade, in der theme.css
 * nach tokens.css lädt.
 */
export function rolesFromCss(primitivesCss, tokensCss, themeCss = '') {
  const prim = declarations(primitivesCss, ':root');
  const resolve = (set) => Object.fromEntries(Object.entries(set).map(([name, value]) => {
    const ref = /^var\(--tl-([a-z0-9-]+)\)$/.exec(value);
    if (!ref) return [name, value];
    if (!(ref[1] in prim)) throw new Error(`${name}: Referenz auf unbekannte Primitive ${ref[1]}`);
    return [name, prim[ref[1]]];
  }));
  const light = resolve(declarations(tokensCss, ':root'));
  const dark = { ...light, ...resolve(declarations(tokensCss, '[data-tl-mode="dark"]')) };
  if (themeCss) {
    const id = /\[data-tl-theme="([a-z0-9-]+)"\]/.exec(themeCss)?.[1];
    const both = resolve(declarations(themeCss, `[data-tl-theme="${id}"]`));
    Object.assign(light, both);
    Object.assign(dark, both, resolve(declarations(themeCss, `[data-tl-theme="${id}"][data-tl-mode="dark"]`)));
  }
  return { light, dark };
}

if (process.argv[1] === fileURLToPath(import.meta.url)) {
  const dist = new URL('../dist/', import.meta.url);
  const [themePath, outPath] = process.argv.slice(2);
  const roles = rolesFromCss(readFileSync(new URL('primitives.css', dist), 'utf8'),
    readFileSync(new URL('tokens.css', dist), 'utf8'), themePath ? readFileSync(themePath, 'utf8') : '');
  const out = themePath ? (outPath ?? themePath.replace(/\.theme\.css$/, '.roles.json')) : new URL('roles.generated.json', dist);
  writeFileSync(out, JSON.stringify(roles, null, 2) + '\n');
  console.log(`geschrieben: ${out} (${Object.keys(roles.light).length} Rollen)`);
}
```

Verweist eine Rolle in `dist/tokens.css` auf eine andere Rolle statt auf eine Primitive, meldet `resolve` sie als unbekannte Primitive; dann `resolve` um die schon aufgelösten Rollen desselben Modus erweitern, statt die Meldung zu unterdrücken.
