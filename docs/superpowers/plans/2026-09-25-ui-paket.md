# UI-Paket — Stufe C mit fremder Komponentenbibliothek

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ein Kundenmodul ersetzt benannte TopLogic-Ressourcen und registriert eigene React-Komponenten unter TopLogic-Namen; jede Komponente der MBUI-Schnittmenge hat einen Vertrag in Muss und Kann; ein Konformitätstest-Harness in der Bridge prüft das Muss, unsere Controls bestehen ihn zuerst; ein Referenzprojekt zeigt Button und Dialog auf MUI im TopLogic-Layout; ein Theme darf ein UI-Paket benennen.

**Architecture:** Framework (`~/git/tl8-wt-29584`, Modul `com.top_logic.layout.react`): `@Key` an der Ressourcenliste macht `config:operation` auf benannte Einträge wirksam; Vitest mit jsdom bei der Bridge trägt den Harness, der eine registrierte Komponente mit dem Zustand aus dem Vertrag mountet und die Kommandos am gestubbten Kommandokanal prüft; `package` am Ressourceneintrag und `ui-package` am Theme filtern die Ressourcenliste je aktivem Theme. Paket (`design-system/`): Verträge als `*.contract.md` mit `## Muss`, `## Kann`, `## Konformität`; im Konformitätsteil ein JSON-Block mit Fällen, den der Harness liest; `publish-to-worktree.mjs` kopiert die Verträge in die Bridge. `examples/mui-adapter/`: eigenes npm-Projekt mit MUI, Adapter aus unseren Rollen, zwei Komponenten, Harness grün.

**Tech Stack:** Java 21 + TypedConfiguration + JUnit 3 (Framework); TypeScript, React 19, Vite 6, Vitest 3, `@testing-library/react` 16, `@testing-library/user-event` 14, jsdom 25 (Bridge-Harness); Node 22, `node:test`, keine Abhängigkeit (Paket); MUI 6 + Emotion 11 (nur `examples/`).

**Spec:** `docs/superpowers/specs/2026-09-25-ui-paket-design.md`

 * Tests for {@link ClientResources}: a second configuration fragment replaces or removes a named

public class TestClientResources extends TestCase {

	private static final String NS = " xmlns:config='" + ConfigurationSchemaConstants.CONFIG_NS + "' ";

	/** Tokens, components depending on them, and the controls bundle. */
	private static final String BASE = "<config class='" + ClientResources.class.getName() + "'" + NS + ">"
		+ "<resources>"
		+ "<stylesheet name='tokens' resource='/style/tokens.css'/>"
		+ "<stylesheet name='components' resource='/style/components.css' requires='tokens'/>"
		+ "<module-script name='controls' resource='/script/controls.js'/>"
		+ "</resources>"
		+ "</config>";

	/** A customer module dropping the component styles and adding its own bundle after ours. */
	private static final String CUSTOMER = "<config class='" + ClientResources.class.getName() + "'" + NS + ">"
		+ "<resources>"
		+ "<stylesheet name='components' config:operation='remove'/>"
		+ "<module-script name='mbui' resource='/script/mbui.js' requires='controls'/>"
		+ "</resources>"
		+ "</config>";

	/** A customer module replacing the component styles by its own file. */
	private static final String REPLACE = "<config class='" + ClientResources.class.getName() + "'" + NS + ">"
		+ "<resources>"
		+ "<stylesheet name='components' config:operation='update' resource='/style/mbui.css'/>"
		+ "</resources>"
		+ "</config>";

	/** A customer module removing what another entry still requires. */
	private static final String DANGLING = "<config class='" + ClientResources.class.getName() + "'" + NS + ">"
		+ "<resources>"
		+ "<stylesheet name='tokens' config:operation='remove'/>"
		+ "</resources>"
		+ "</config>";

	/** The second fragment removes an entry by name and keeps the rest, in dependency order. */
	public void testRemoveByName() throws ConfigurationException, IOException {
		String styles = styles(service(BASE, CUSTOMER));

		assertTrue(styles, styles.contains("/style/tokens.css"));
		assertFalse(styles, styles.contains("/style/components.css"));
	}

	/** The second fragment replaces the resource of a named entry. */
	public void testUpdateByName() throws ConfigurationException, IOException {
		String styles = styles(service(BASE, REPLACE));

		assertTrue(styles, styles.contains("/style/mbui.css"));
		assertFalse(styles, styles.contains("/style/components.css"));
		assertTrue(styles, styles.indexOf("/style/tokens.css") < styles.indexOf("/style/mbui.css"));
	}

	/** A module script added by the customer is emitted after the one it requires. */
	public void testCustomerScriptAfterOurs() throws ConfigurationException, IOException {
		String scripts = scripts(service(BASE, CUSTOMER));

		assertTrue(scripts, scripts.indexOf("/script/controls.js") < scripts.indexOf("/script/mbui.js"));
	}

	/** Removing an entry another one requires is an error, not a silent omission. */
	public void testRequiresOnRemovedEntryIsAnError() throws ConfigurationException {
		BufferingProtocol log = new BufferingProtocol();
		service(log, BASE, DANGLING);

		assertTrue(log.getError(), log.hasErrors());
		assertTrue(log.getError(), log.getError().contains("'components' requires unknown resource 'tokens'"));
	}

	private static ClientResources service(String... fragments) throws ConfigurationException {
		BufferingProtocol log = new BufferingProtocol();
		ClientResources result = service(log, fragments);
		assertFalse(log.getError(), log.hasErrors());
		return result;
	}

	private static ClientResources service(BufferingProtocol log, String... fragments) throws ConfigurationException {
		Map<String, ConfigurationDescriptor> roots = new HashMap<>();
		roots.put("config", TypedConfiguration.getConfigurationDescriptor(ClientResources.Config.class));
		DefaultInstantiationContext context = new DefaultInstantiationContext(log);
		ConfigurationReader reader = new ConfigurationReader(context, roots);
		reader.setSources(java.util.Arrays.stream(fragments).map(CharacterContents::newContent).toList());
		ClientResources.Config config = (ClientResources.Config) reader.read();
		return new ClientResources(context, config);
	}

	private static String styles(ClientResources service) throws IOException {
		StringWriter buffer = new StringWriter();
		service.writeStyleRefs(new TagWriter(buffer), "");
		return buffer.toString();
	}

	private static String scripts(ClientResources service) throws IOException {
		StringWriter buffer = new StringWriter();
		service.writeScriptRefs(new TagWriter(buffer), "");
		return buffer.toString();
	}

	public static Test suite() {
		return ServiceTestSetup.createSetup(TestClientResources.class, TypeIndex.Module.INSTANCE);
	}

}

Die Fälle stehen als JSON-Block im Vertrag (`## Konformität`); so bleibt die Zustandstabelle für Menschen lesbar und der Harness braucht keinen Tabellen-Parser. Ein Paket-Test (Task 6) hält Tabelle und Fälle deckungsgleich.

  state: Record<string, unknown>;

// Der Konformitätstest-Harness (Spec 2026-09-25-ui-paket-design.md §5). Er prüft den Muss-Teil eines
// Vertrags gegen die Komponente, die unter dem TopLogic-Namen registriert ist. Er ist das Werkzeug
// des Kunden vor seinem Deploy; unsere eigenen Controls bestehen ihn zuerst.
import { describe, it, expect, beforeEach } from 'vitest';
import { render, screen, cleanup, act } from '@testing-library/react';
import userEvent from '@testing-library/user-event';
import { React, getComponent, TLControlContext, KeyboardScopeProvider } from 'tl-react-bridge';
import { commandLog } from './setup';

export interface ContractCase {
  name: string;
  state: Record<string, unknown>;
  trigger: string;
  on?: string;
  expect: { command: string; args?: Record<string, unknown> } | null;
  trap?: boolean;
  renders?: false;
  dom?: { selector?: string; attributes?: Record<string, string | null>; text?: string; classes?: string[] };
}

export interface Contract {
  module: string;
  cases: ContractCase[];
}

const CONTROL_ID = 'c1';

/** Der JSON-Block unter "## Konformität". Alles andere im Vertrag ist für Menschen. */
export function readContract(markdown: string): Contract {
  const section = markdown.split(/^## Konformität\s*$/m)[1];
  if (!section) throw new Error('Vertrag ohne Abschnitt "## Konformität"');
  const block = /```json\s*([\s\S]*?)```/.exec(section);
  if (!block) throw new Error('Kein JSON-Block unter "## Konformität"');
  const contract = JSON.parse(block[1]) as Contract;
  if (typeof contract.module !== 'string' || !Array.isArray(contract.cases)) {
    throw new Error('Konformität braucht "module" und "cases"');
  }
  return contract;
}

/** Ein Zustandsspeicher, wie ihn die Bridge je Control führt — hier ohne SSE. */
function store(state: Record<string, unknown>) {
  let current = { ...state };
  const subscribers = new Set<() => void>();
  return {
    getSnapshot: () => current,
    subscribeStore: (cb: () => void) => { subscribers.add(cb); return () => subscribers.delete(cb); },
    replaceState: (next: Record<string, unknown>) => { current = { ...next }; subscribers.forEach((cb) => cb()); },
    applyPatch: (patch: Record<string, unknown>) => { current = { ...current, ...patch }; subscribers.forEach((cb) => cb()); },
  };
}

function mountCase(module: string, state: Record<string, unknown>) {
  const Component = getComponent(module);
  if (!Component) throw new Error(`Modul ${module} ist nicht registriert — kein Vertrag ohne Komponente`);
  const value = { controlId: CONTROL_ID, windowName: 'test', store: store(state) };
  return render(
    React.createElement(TLControlContext.Provider, { value: value as never },
      React.createElement(KeyboardScopeProvider, null,
        React.createElement(Component, { controlId: CONTROL_ID, state }))));
}

/** Das Element, das den Auslöser bekommt: das Control selbst oder das erste Bedienelement darin. */
function target(container: HTMLElement, on?: string): HTMLElement {
  if (on) {
    const chosen = container.querySelector<HTMLElement>(on);
    if (!chosen) throw new Error(`Auslöser-Ziel ${on} nicht gefunden`);
    return chosen;
  }
  const byId = container.querySelector<HTMLElement>('#' + CONTROL_ID);
  const el = byId ?? container.firstElementChild as HTMLElement | null;
  if (!el) throw new Error('nichts gerendert');
  const inner = el.matches('button,input,select,textarea,[tabindex]') ? el
    : el.querySelector<HTMLElement>('button,input,select,textarea,[tabindex]');
  return inner ?? el;
}

async function fire(trigger: string, container: HTMLElement, on?: string) {
  const user = userEvent.setup();
  const el = target(container, on);
  if (trigger === 'click') { await user.click(el); return; }
  if (trigger === 'enter') { el.focus(); await user.keyboard('{Enter}'); return; }
  if (trigger === 'space') { el.focus(); await user.keyboard(' '); return; }
  if (trigger === 'escape') { el.focus(); await user.keyboard('{Escape}'); return; }
  if (trigger === 'backdrop') { await user.click(container.querySelector<HTMLElement>('#' + CONTROL_ID)!); return; }
  if (trigger.startsWith('gesture:')) {
    // Die Geste geht an das Dokument; der Dispatcher der Bridge leitet sie in den Scope.
    const { initKeyboardDispatcher } = await import('../bridge/keyboard-dispatcher');
    initKeyboardDispatcher();
    await user.keyboard(gestureToUserEvent(trigger.slice('gesture:'.length)));
    return;
  }
  if (trigger.startsWith('change:')) {
    const input = el as HTMLInputElement;
    await user.clear(input);
    await user.type(input, trigger.slice('change:'.length));
    await user.tab();
    return;
  }
  if (trigger.startsWith('select:')) {
    await user.selectOptions(el, trigger.slice('select:'.length));
    return;
  }
  if (trigger.startsWith('range:')) {
    // Ein Schieberegler nimmt keine Tastatureingabe an: Wert setzen, change und pointerup auslösen.
    const { fireEvent } = await import('@testing-library/react');
    fireEvent.change(el, { target: { value: trigger.slice('range:'.length) } });
    fireEvent.pointerUp(el);
    return;
  }
  if (trigger === 'none') return;
  throw new Error(`unbekannter Auslöser ${trigger}`);
}

/** "CTRL+S" → "{Control>}s{/Control}", "ESCAPE" → "{Escape}", "ENTER" → "{Enter}". */
function gestureToUserEvent(gesture: string): string {
  const parts = gesture.toUpperCase().split('+');
  const key = parts.pop()!;
  const named: Record<string, string> = { ESCAPE: '{Escape}', ENTER: '{Enter}', SPACE: ' ', TAB: '{Tab}' };
  const keyText = named[key] ?? key.toLowerCase();
  const mods = parts.map((m) => ({ CTRL: 'Control', SHIFT: 'Shift', ALT: 'Alt', META: 'Meta' })[m] ?? m);
  return mods.map((m) => `{${m}>}`).join('') + keyText + mods.reverse().map((m) => `{/${m}}`).join('');
}

export function runContract(contract: Contract): void {
  if (!getComponent(contract.module)) {
    throw new Error(`kein Vertrag für Modul ${contract.module}: nicht registriert`);
  }
  describe(`Vertrag ${contract.module}`, () => {
    beforeEach(() => cleanup());
    for (const c of contract.cases) {
      it(c.name, async () => {
        const { container } = mountCase(contract.module, c.state);
        if (c.renders === false) {
          expect(container.querySelector('#' + CONTROL_ID)).toBeNull();
          return;
        }
        if (c.trap !== undefined) {
          const { activeTrapCount } = await import('../bridge/focus-trap');
          expect(activeTrapCount() > 0).toBe(c.trap);
        }
        if (c.dom) {
          const el = c.dom.selector ? container.querySelector<HTMLElement>(c.dom.selector) : container.querySelector<HTMLElement>('#' + CONTROL_ID);
          expect(el, `DOM ${c.dom.selector ?? '#' + CONTROL_ID}`).not.toBeNull();
          for (const [name, value] of Object.entries(c.dom.attributes ?? {})) {
            if (value === null) expect(el!.hasAttribute(name), `${name} darf nicht gesetzt sein`).toBe(false);
            else expect(el!.getAttribute(name), name).toBe(value);
          }
          if (c.dom.text !== undefined) expect(el!.textContent?.trim()).toBe(c.dom.text);
          if (process.env.TL_CONFORMANCE_KANN && c.dom.classes) {
            for (const cls of c.dom.classes) expect(el!.classList.contains(cls), `Klasse ${cls}`).toBe(true);
          }
        }
        const sentCommands = () => commandLog.filter((e) => e.controlId === CONTROL_ID);
        await act(async () => { await fire(c.trigger, container, c.on); });
        // Ein entprelltes Feld sendet erst nach VALUE_DEBOUNCE_MS; der Harness wartet, statt zu raten.
        if (c.expect && sentCommands().length === 0) {
          const { VALUE_DEBOUNCE_MS } = await import('tl-react-bridge');
          await act(async () => { await new Promise((r) => setTimeout(r, VALUE_DEBOUNCE_MS + 50)); });
        }
        const sent = sentCommands();
        if (c.expect === null) {
          expect(sent).toEqual([]);
        } else {
          expect(sent.map((e) => e.command)).toContain(c.expect.command);
          if (c.expect.args) {
            const match = sent.find((e) => e.command === c.expect!.command)!;
            expect(match.args).toMatchObject(c.expect.args);
          }
        }
      });
    }
  });
}

Eine Kundenkomponente, die unter dem TopLogic-Namen `TLButton` registriert ist (Stufe C), hält den
**Muss**-Teil ein: Sie bekommt den Zustand unten und löst die genannten Aktionen aus. TopLogic

Werkzeuge passt.

## Muss

### Zustand

Vom Server über `useTLState()`:

| Schlüssel | Typ | Bedeutung |
|---|---|---|
| `label` | string | Beschriftung; bei icon-only der zugängliche Name. |
| `image` | string, optional | Kodiertes ThemeImage für das Icon. |
| `displayMode` | `icon-only` \| `icon-label` \| `label-only`, optional | Standard `label-only`. Ohne `image` fällt `icon-only` auf `label-only` zurück. |
| `appearance` | `primary` \| `ghost` \| `link`, optional | Fehlt er, gilt die Vorgabe des Containers (`ButtonDefaults`), sonst `secondary`. |
| `tone` | `danger`, optional | Destruktive Aktion. Nicht mit `link`. |
| `size` | `small`, optional | Nur mit `displayMode: icon-only` wirksam. |
| `disabled` | boolean | Der Button ist nicht bedienbar; er sendet nichts. |
| `active` | boolean | Der Button ist gedrückt oder die geltende Alternative. |
| `hidden` | boolean | Rendert nichts. Die Tastenbindung bleibt registriert und lehnt ab. |
| `tooltip` | string, optional | Tooltip-Text; bei icon-only Rückfall auf `label`. |
| `keyGesture` | string, optional | Tastengeste im umgebenden Scope (`useKeyboardBinding`). |
| `navigateUrl` | string, optional | Klick navigiert dorthin statt zu senden. |
| `navigateNewWindow` | boolean, optional | Mit `navigateUrl`: in einem neuen Fenster. |
| `cssClasses` | string, optional | Zusätzliche Klassen des Kommandos; werden an `className` durchgereicht. |

| Auslöser | Aktion |
|---|---|
| Klick, Enter, Leertaste | `sendCommand('click')` — oder `navigateUrl` öffnen, wenn gesetzt. |

| `disabled` | nichts — kein Kommando, auf keinem Weg. |

Fläche, Beschriftung und Linie je Erscheinung; Hover und Active eine Stufe weiter auf derselben Rampe.

| `ghost` | wie secondary beim Zeigen und Drücken | `--tl-text-primary` | — |
| `link` | — | `--tl-text-link`, `--tl-text-link-hover` | — |
| `danger` + `primary` | `--tl-status-error-surface`, `--tl-status-error-surface-hover`, `--tl-status-error-surface-active` | `--tl-text-on-status-error`, `--tl-text-on-status-error-hover`, `--tl-text-on-status-error-active` | — |
| `danger` + `secondary` / `ghost` | Zeigen: `--tl-status-error-surface` (Beschriftung `--tl-text-on-status-error`); Drücken: `--tl-status-error-surface-active` (Beschriftung `--tl-text-on-status-error-active`) | `--tl-status-error-text` (Grundzustand) | `--tl-status-error-border` (nur secondary; folgt beim Zeigen und Drücken der Fläche) |
| gedrückt (`aria-pressed`) | `--tl-surface-brand-subtle`, `--tl-surface-brand-subtle-hover` | `--tl-text-primary` | `--tl-border-interactive` |
| `disabled` (vom Kontrast-Gate ausgenommen) | `--tl-surface-disabled` | `--tl-text-disabled` | `--tl-border-disabled` |

```js
// Liest die Rollen des Design Systems als Hex je Modus und schreibt src/roles.generated.json.
// MUI rechnet contrastText und Hover-Töne selbst aus Hexwerten; mit var(--tl-…) kann es nichts
// anfangen. Darum zur Bauzeit. Erzeugt, nie von Hand geändert.
import { readFileSync, writeFileSync } from 'node:fs';
import { fileURLToPath } from 'node:url';

const DECL = /--tl-([a-z0-9-]+)\s*:\s*([^;]+);/g;

function block(css, selector) {
  const start = css.indexOf(selector + ' {');
  if (start < 0) return '';
  const end = css.indexOf('}', start);
  return css.slice(start, end);
}

function declarations(text) {
  const out = {};
  for (const m of text.matchAll(DECL)) out[m[1]] = m[2].trim();
  return out;
}

/** Rollen je Modus als Hex. Dunkel erbt aus hell, was es nicht setzt — wie die Kaskade. */
export function rolesFromCss(primitivesCss, tokensCss, themeCss = '') {
  const prim = declarations(primitivesCss);
  const resolve = (value, name) => {
    const ref = /^var\(--tl-([a-z0-9-]+)\)$/.exec(value);
    if (!ref) return value;
    const hex = prim[ref[1]];
    if (!hex) throw new Error(`${name}: Referenz auf unbekannte Primitive ${ref[1]}`);
    return hex;
  };
  const light = {};
  for (const [name, value] of Object.entries(declarations(block(tokensCss, ':root')))) light[name] = resolve(value, name);
  const dark = { ...light };
  for (const [name, value] of Object.entries(declarations(block(tokensCss, '[data-tl-mode="dark"]')))) dark[name] = resolve(value, name);
  if (themeCss) {
    const id = /\[data-tl-theme="([a-z0-9-]+)"\]/.exec(themeCss)?.[1];
    for (const [name, value] of Object.entries(declarations(block(themeCss, `[data-tl-theme="${id}"]`)))) light[name] = resolve(value, name);
    for (const [name, value] of Object.entries(declarations(block(themeCss, `[data-tl-theme="${id}"][data-tl-mode="dark"]`)))) dark[name] = resolve(value, name);
  }
  return { light, dark };
}

if (process.argv[1] === fileURLToPath(import.meta.url)) {
  const ds = new URL('../../../design-system/dist/', import.meta.url);
  const theme = process.argv[2] ? readFileSync(process.argv[2], 'utf8') : '';
  const roles = rolesFromCss(readFileSync(new URL('primitives.css', ds), 'utf8'), readFileSync(new URL('tokens.css', ds), 'utf8'), theme);
  const out = new URL('../src/roles.generated.json', import.meta.url);
  writeFileSync(out, JSON.stringify(roles, null, 2) + '\n');
  console.log(`geschrieben: src/roles.generated.json (${Object.keys(roles.light).length} Rollen)`);
}
```

// MUI-Theme aus den Rollen des Design Systems. Eine Palette für beide Systeme: Was derive für den
// Kunden rechnet, landet über roles.generated.json auch hier.
import { createTheme, type Theme } from '@mui/material/styles';
import roles from './roles.generated.json';

type Mode = 'light' | 'dark';
type Roles = Record<string, string>;

function palette(r: Roles, mode: Mode) {
  const status = (s: string) => ({ main: r[`status-${s}-surface`], contrastText: r[`text-on-status-${s}`] });
  return {
    mode,
    primary: { main: r['surface-brand'], dark: r['surface-brand-active'], light: r['surface-brand-hover'], contrastText: r['text-on-brand'] },
    error: status('error'), warning: status('warning'), success: status('success'), info: status('info'),
    background: { default: r['surface-base'], paper: r['surface-layer'] },
    text: { primary: r['text-primary'], secondary: r['text-secondary'], disabled: r['text-disabled'] },
    divider: r['border-separator'],
  };
}

export function createTlTheme(mode: Mode): Theme {
  const r = (roles as Record<Mode, Roles>)[mode];
  return createTheme({
    palette: palette(r, mode),
    shape: { borderRadius: 4 },
    typography: { fontFamily: 'Inter, system-ui, sans-serif' },
  });
}

/** Folgt data-tl-mode am html; ruft apply sofort und bei jeder Änderung. Gibt die Abmeldung zurück. */
export function followTlMode(apply: (mode: Mode) => void): () => void {
  const html = document.documentElement;
  const read = (): Mode => (html.getAttribute('data-tl-mode') === 'dark' ? 'dark' : 'light');
  apply(read());
  const observer = new MutationObserver(() => apply(read()));
  observer.observe(html, { attributes: true, attributeFilter: ['data-tl-mode'] });
  return () => observer.disconnect();
}
```

`shape.borderRadius` und `fontFamily` sind hier Literale, weil MUI Zahlen und Namen will; sie kommen aus `--tl-radius-sm` (4 px) und `--tl-font-sans`. Wer sie aus `dist/` ziehen will, erweitert `roles-to-mui.mjs` um die Maße — offen, siehe Spec §8.

```tsx
import { React, useTLState, useTLCommand, useKeyboardBinding } from 'tl-react-bridge';
import type { TLCellProps } from 'tl-react-bridge';
import Button from '@mui/material/Button';
import { TlThemeProvider } from './TlThemeProvider';

const { useCallback } = React;

/**
 * TLButton auf MUI. Muss-Teil aus button.contract.md: Zustand lesen, click senden, disabled sendet
 * nichts, hidden rendert nichts und lehnt die Geste ab, aria-pressed bei active, aria-label bei
 * icon-only. Aussehen ist MUI.
 */
const MBButton: React.FC<TLCellProps> = ({ controlId }) => {
  const state = useTLState();
  const send = useTLCommand();
  const label = state.label as string;
  const disabled = state.disabled === true;
  const hidden = state.hidden === true;
  const active = state.active === true;
  const iconOnly = state.displayMode === 'icon-only' || Boolean(state.image);
  const navigateUrl = state.navigateUrl as string | undefined;

  const click = useCallback(() => {
    if (navigateUrl) {
      if (state.navigateNewWindow === true) window.open(navigateUrl, '_blank'); else window.location.assign(navigateUrl);
      return;
    }
    void send('click');
  }, [send, navigateUrl, state.navigateNewWindow]);

  useKeyboardBinding(state.keyGesture as string | undefined, () => {
    if (disabled || hidden) return false;
    click();
    return true;
  });

  if (hidden) return null;

  const variant = state.appearance === 'primary' ? 'contained' : state.appearance === 'link' ? 'text' : 'outlined';
  const color = state.tone === 'danger' ? 'error' : 'primary';
  return (
    <TlThemeProvider>
      <Button id={controlId} type="button" variant={variant} color={color} disabled={disabled}
        onClick={click} aria-pressed={active ? true : undefined} aria-label={iconOnly ? label : undefined}
        className={state.cssClasses as string | undefined}>
        {label}
      </Button>
    </TlThemeProvider>
  );
};

export default MBButton;
```

`src/MBDialog.tsx`:

```tsx
import { React, ReactDOM, useTLState, useTLCommand, useKeyboardBinding, useFocusTrap, KeyboardScopeProvider, TLChild } from 'tl-react-bridge';
import type { TLCellProps } from 'tl-react-bridge';
import Dialog from '@mui/material/Dialog';
import { TlThemeProvider } from './TlThemeProvider';

const { useCallback, useRef } = React;

const EscapeToClose: React.FC<{ onClose: () => void }> = ({ onClose }) => {
  useKeyboardBinding('ESCAPE', () => { onClose(); return true; });
  return null;
};

/**
 * TLDialog auf MUI. Muss-Teil aus dialog.contract.md: Escape und Backdrop senden close, closable
 * false blockt beides, open false rendert nichts. Stapel: eigener Tastatur-Scope; die Fokusfalle
 * registriert der Dialog selbst, weil MUI Hülle und Fenster in einem zeichnet. Das Portal hängt an
 * body — unter html, wo data-tl-mode steht.
 */
const MBDialog: React.FC<TLCellProps> = ({ controlId }) => {
  const state = useTLState();
  const send = useTLCommand();
  const open = state.open === true;
  const closable = state.closable !== false;
  const closeOnBackdrop = state.closeOnBackdrop !== false;
  const paperRef = useRef<HTMLDivElement | null>(null);

  const close = useCallback(() => { void send('close'); }, [send]);
  useFocusTrap(open, paperRef, 'field');

  if (!open) return null;

  return ReactDOM.createPortal(
    <TlThemeProvider>
      <KeyboardScopeProvider>
        {closable && <EscapeToClose onClose={close} />}
        <Dialog open id={controlId} disableEscapeKeyDown disablePortal
          onClose={(_e, reason) => { if (closable && closeOnBackdrop && reason === 'backdropClick') close(); }}
          PaperProps={{ ref: paperRef }}>
          <TLChild control={state.child} />
        </Dialog>
      </KeyboardScopeProvider>
    </TlThemeProvider>,
    document.body,
  );
};

export default MBDialog;
```

`disablePortal` an MUI, weil der Dialog das Portal selbst setzt; so hat das Wurzelelement die `id` und der Harness findet den Backdrop. Der Fall `backdrop closes` klickt `#c1`; bei MUI ist `#c1` der Dialog-Wrapper, dessen Klick auf dem Backdrop landet — trifft der Klick das Paper, den Selektor im Harness-Aufruf nicht ändern, sondern in `MBDialog` `id={controlId}` an den Backdrop-Container hängen (`slotProps.root`).
